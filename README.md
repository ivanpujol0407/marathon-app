# 🏃 CPH/27 Marathon Tracker

**Copenhagen Marathon 2027 Training Plan — Sub-3:52 @ 5:30/km**

A 51-week periodized marathon training app with workout logging, HR zone tracking, progress charts, and nutrition/recovery guidelines.

## Features

- 📅 Full 51-week training plan (4 phases: Base → Build → Peak → Taper)
- 📝 Log workouts: distance, time, pace (auto-calculated), notes
- ❤️ HR Zone tagging (Z1–Z5) with personalized bpm ranges (Max HR: 190 bpm)
- 📊 Progress charts: weekly volume, long run progression, pace trends, zone distribution
- ⚖️ Weight tracking with chart
- 📖 Guidelines: nutrition, sleep/recovery, race pacing, equipment
- 📱 Mobile-first dark mode UI — optimized for smartphone use
- 💾 Data persists in localStorage

## Tech Stack

- Next.js 14
- React 18
- Tailwind CSS
- Recharts
- Lucide React Icons

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000)

## Deploy

Push to GitHub → connect to [Vercel](https://vercel.com) → auto-deploys.

## Add to Phone

Open your Vercel URL on your phone → Share → Add to Home Screen.
